# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its full text applies to every space the project manages: the issue tracker,
pull requests, discussions and code review.

## In short

- Be respectful and assume good faith. Disagree with ideas, not with people.
- Give feedback that is specific and kind; receive it gracefully.
- Harassment, insults, personal attacks and discriminatory language or
  imagery are not tolerated, in any form.
- Do not publish other people's private information.

## Reporting

If you experience or witness behaviour that breaks these rules, please tell
the maintainer, [@DmytroPalahin](https://github.com/DmytroPalahin), privately,
using the contact details on that GitHub profile rather than a public issue.

Reports are handled confidentially. The maintainer may remove, edit or
reject comments, commits, issues and other contributions that do not follow
this code of conduct, and may ban contributors, temporarily or permanently,
for behaviour deemed inappropriate, threatening or harmful.
